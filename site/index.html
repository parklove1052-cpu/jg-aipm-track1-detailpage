가져올 것 / 가져오지 않을 것

  • 가져온 것 — ① 덜어내기 서사(전 범위 → 나올 것만) ② 별점 우선순위라는 장치 ③ 반론을 먼저 말하고 해소하는 순서 ④ 수치를 큰 숫자로 못 박는 블록 ⑤ 집필진 편지로 닫는 마무리
  • 가져오지 않은 것 — 인물 사진·후기 영상·합격률·만족도 비율. 확인된 수치가 아니면 지어내지 않는다는 과제 지침에 따라 해당 자리는 ○○ + “예시” 로 비워 두거나 아예 넣지 않았습니다.

04. 제작 노트

사용한 AI 도구

  • Claude (Claude Code) — 레퍼런스 34장 판독, 섹션 구조 분석, 카피 작성, 상세페이지 HTML/CSS 직접 작성
  • Playwright + 설치된 Chrome — HTML 섹션을 860px PNG 로 렌더링 (AI 가 쓴 코드로 자동 실행)
  • Pillow (Python) — 24프레임을 이어 GIF 로 묶음
  • 이미지 생성 AI 는 쓰지 않았습니다. 레퍼런스의 사진·인물·로고를 가져오지 않기 위해, 모든 화면을 코드로 직접 그렸습니다.

핵심 프롬프트 원문

① 레퍼런스 34장을 6장씩 세로로 이어 붙여 한 번에 보고, 위에서 아래로
   섹션을 끊어라. 섹션마다 "구매자를 어떻게 설득하는가"를 한 줄로 쓰고,
   권위·증명·희소성·반론처리 중 무엇에 해당하는지 분류해라.
   GIF로 움직이던 자리는 따로 표시해라.
② 레퍼런스의 '만점자 영상' 섹션을 우리 상품으로 바꾼다.
   인물·후기는 쓸 수 없으니 움직임의 '역할'만 가져와라.
   그 자리가 하던 일은 "이 자료를 믿어도 된다"는 설득이다.
   우리 상품에서 같은 일을 하는 움직임은 무엇인가?
   → 두꺼운 수험서가 얇아지는 과정을 보여 줘라. 소구점이 '덜어내기'이므로
     덜어내는 동작 자체가 증명이 된다.
③ 상세페이지 카피에 합격률·수강생 수·후기를 절대 지어내지 마라.
   레퍼런스에 숫자가 있던 자리는 ○○로 비우고 "예시" 배지를 붙여라.
   확인되지 않은 수치를 넣느니 그 섹션을 통째로 빼라.
④ 모바일에서 읽히게 만들어라. 가로 860px 기준으로 본문 23px 이상,
   헤드라인 42px 이상. 한 섹션에 메시지는 하나만. 글자가 7줄을 넘으면
   표나 카드로 쪼개라.

버린 시도와 이유

시도한 것버린 이유
적중 CASE 01·02·03 를 그대로 옮기기“적중” 도장은 실제 적중 기록이 있어야 성립합니다. 우리 상품에는 근거가 없어 증명 섹션 대신 ‘개념+기출 병치’ 설명 섹션으로 바꿨습니다.
합격생 인터뷰 영상 자리에 후기 카드 넣기실재하지 않는 후기를 만드는 일이라 과제 지침 위반입니다. 같은 자리를 제품 자체가 움직이는 GIF 로 채웠습니다.
“합격률 ○○%” 수치 블록○○ 로 비워도 합격률이라는 항목 자체가 없는 수치를 암시합니다. 섹션을 통째로 뺐습니다.
GIF 를 인물 등장 연출로 만들기인물 이미지가 필요해 불가. 종이가 줄어드는 물리적 변화로 바꾸니 소구점(덜어내기)과 움직임이 같은 말을 하게 됐습니다.
섹션을 레퍼런스처럼 17개 전부 만들기근거 없는 증명 섹션이 절반이라 남는 것이 적었습니다. 9개로 줄이되 설득 순서는 그대로 두는 쪽을 택했습니다.
첫 GIF 저장 (팔레트 변환)프레임마다 팔레트를 따로 만들어 1프레임만 저장됐습니다. RGB 로 넘기고 PIL 이 변환하게 고쳤습니다.
레퍼런스의 이미지·문구·로고는 가져오지 않았습니다. 섹션 순서와 설득 방식만 참고했고, 화면은 전부 새로 그렸습니다. 합격률·후기·만족도 등 확인되지 않은 수치는 넣지 않았으며, 자리만 잡은 곳은 ○○ + “예시” 로 표시했습니다.
